# Repository conventions
Use camelCase for all names.
## Asset naming patterns
- objObject0
- sprSprite0
- rmRoom0 for standalone menus or non-stage rooms
- stgStage0 for gameplay stages
- fnFont0
- psParticle0
- ptPath0
- sfxSFX0 for sound effects
- muMusic0 for music
- tsTileSet0 for tile sets
## Notes
- Scripts do not start with `scr_`; keep them named like normal functions in camelCase.
- `rm` is used for standalone menu rooms.
- `stg` is used for game stage rooms.
- Sound effects should start with `sfx`.
- Music should start with `mu`.
