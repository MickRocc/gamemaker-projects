# gamemaker-projects
This Repository has Game Maker projects in it.

## Naming conventions
Use camelCase for all names.

- objObject0
- sprSprite0
- rmRoom0 for standalone menu rooms
- stgStage0 for gameplay stages
- fnFont0
- psParticle0
- ptPath0
- sfxSFX0 for sound effects
- muMusic0 for music
- tsTileSet0 for tile sets

Scripts do not start with `scr_`; use normal camelCase function names instead.

For rooms:
- `rm` is used for standalone game menus
- `stg` is used for game stages

For sounds:
- `sfx` is used for sound effects
- `mu` is used for music
